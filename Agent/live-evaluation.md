## Two-pass normative review

`Agent/normative_review.py` runs all selected source-chunk extractions before a separate audit pass. Extraction records the statement's proposed kind, wording, conditions, scope and source quotation. The auditor must cover every extracted statement and separately assess the wording and kind; it can also report quoted omissions. Structural checks, conservative triage flags and incremental output do not establish semantic accuracy or completeness. Both passes use the same model. The optional `pipeline.py --normative-resolved ...` gate runs these passes before the older staged variation analysis; incomplete or flagged results block that group's handoff. A clean model audit is still provisional, and the later staged reviewer does not consume its statements as verified facts.
